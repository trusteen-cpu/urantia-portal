배포 3단계
------------------------------------------------------------------
1. 이 폴더에서
       python generate_audio_daily.py
   → audio/01_reading.mp3, 02_sermon.mp3, 04_prayer.mp3 생성
   (윈도우는 RUN.bat 더블클릭)

2. 수노에서 「불씨는 한 분이시라」 곡을 만들어
       audio/03_song.mp3
   로 저장
   · Custom 모드, Instrumental 끄기
   · Lyrics 칸 / Style 칸 내용은 아래 참고

3. 2026-07-27-morning 폴더째 Netlify 에 드래그 앤 드롭

수노 Style 칸
------------------------------------------------------------------
traditional gospel hymn, 3/4 waltz time, slow 76 bpm,
warm baritone solo, piano and church organ, soft strings,
devotional and humble, gentle swell in the chorus,
short intro, minimal outro, under 3 minutes, korean lyrics


재생기 기능
------------------------------------------------------------------
· 화면을 한 번 누르면 낭독부터 자동으로 이어서 재생됩니다
· 반복 단추를 누를 때마다  이어서 재생 → 전체 무한 반복 → 이 메뉴 무한 반복
· 앞뒤 단추로 건너뛰기, 위쪽 메뉴를 눌러 바로 이동
· 진행바를 누르면 그 지점으로 이동, 음소거 단추 있음
· 키보드 : 스페이스 재생·정지, ← → 이전·다음
· audio/03_song.mp3 가 없으면 노래를 자동으로 건너뜁니다
