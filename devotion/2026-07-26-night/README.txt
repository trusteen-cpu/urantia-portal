재생기 기능
------------------------------------------------------------------
· 화면을 한 번 누르면 낭독부터 자동으로 이어서 재생됩니다
· 반복 단추를 누를 때마다  이어서 재생 → 전체 무한 반복 → 이 메뉴 무한 반복
· 앞뒤 단추로 건너뛰기, 위쪽 메뉴를 눌러 바로 이동
· 진행바를 누르면 그 지점으로 이동, 음소거 단추 있음
· 키보드 : 스페이스 재생·정지, ← → 이전·다음
· audio/03_song.mp3 가 없으면 노래를 자동으로 건너뜁니다
