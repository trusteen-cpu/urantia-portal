 배포 3단계
---------------------------------------------------------
 1) 이 폴더에서  python generate_audio_daily.py  실행

 3) 2026-07-28-morning 폴더째 Netlify 에 드래그 앤 드롭

    API 키가 들어 있는 파일입니다.

---------------------------------------------------------
 재생기 사용법
---------------------------------------------------------
  시작하기 → 낭독 → 강론 → 노래 → 기도 자동 연속
  ↻ 버튼   반복 없음 → 전체 무한 반복 → 한 메뉴 무한 반복(배지 1)
  ⏮ ⏭     건너뛰기 (재생 3초 이후 ⏮ 는 처음으로)
  메뉴     낭독/강론/노래/기도 를 눌러 바로 이동
  진행바   눌러서 구간 이동
  키보드   스페이스=재생/정지, ← →=앞뒤 이동
  03_song.mp3 가 없으면 노래는 자동으로 건너뜁니다.

---------------------------------------------------------
 원고를 고치고 싶다면
---------------------------------------------------------
  content.py 를 고친 뒤
    python build_index.py          (화면 글 갱신)
    audio 의 해당 mp3 를 지우고
    python generate_audio_daily.py (음성 갱신)
