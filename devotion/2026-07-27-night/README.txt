 오늘의 취침 묵상 2026-07-27  「잃어도 잃지 않은 사랑」
 유란시아서 148:6.2
 제148편 벳세다에서의 전도사 훈련 · 고난의 오해―욥기에 대한 강연
====================================================

[ 배포 3단계 ]

1) 이 폴더에서 음성 만들기
     python generate_audio_daily.py
   (윈도우에서는 RUN.bat 을 더블클릭해도 됩니다)
   → audio/01_reading.mp3
      audio/02_sermon.mp3
      audio/04_prayer.mp3   가 만들어집니다.

2) 수노(Suno)에서 「잃어도 잃지 않은 사랑」 곡을 만든 뒤
     audio/03_song.mp3   로 저장하십시오.
   가사와 스타일 문구는 lyrics.txt 에 들어 있습니다.

3) 2026-07-27-night 폴더를 통째로 Netlify 에 드래그 앤 드롭
   (https://app.netlify.com/drop)


[ 주의 ]
 * generate_audio_daily.py 에는 일레븐랩스 API 키가 들어 있습니다.
   Netlify 에 올릴 때는 .py 파일을 빼고 올리시는 편이 안전합니다.
   웹 재생에는 index.html 과 audio 폴더만 있으면 됩니다.
 * 이미 만들어진 mp3 는 다시 만들지 않고 건너뜁니다(재과금 방지).
   새로 만들려면 해당 mp3 를 지우고 다시 실행하십시오.
 * 원고(content.py)를 고쳤으면 python build_index.py 를 실행해
   index.html 을 다시 만드십시오. 화면 글과 음성 원고가 항상 같아집니다.


[ 재생기 사용법 ]
 시작 버튼 → 낭독 → 강론 → 노래 → 기도 자동 연속 재생
 ↻  반복 3단 토글 : 반복 없음 → 전체 무한 반복 → 한 메뉴 무한 반복(배지 1)
 ⏮ ⏭  건너뛰기 (재생 3초 이후 ⏮ 은 처음으로)
 상단 메뉴 버튼으로 원하는 구간 바로 이동
 진행바 클릭으로 위치 이동, 🔊 음소거
 키보드 : 스페이스=재생/정지, ← → =앞뒤 이동
 audio/03_song.mp3 이 없으면 노래를 자동으로 건너뜁니다.
