오늘의 아침 묵상 2026-07-29 — 「사랑이 그 증거」
유란시아서 146:3.6 (제146편 갈릴리에서의 첫 전도 여행 › 라마에서의 방문)
================================================================

[ 배포 3단계 ]

1) 이 폴더에서 음성 만들기
      python generate_audio_daily.py
   → audio/01_reading.mp3 (낭독)
      audio/02_sermon.mp3  (강론)
      audio/04_prayer.mp3  (기도)
   * 윈도우에서는 RUN.bat 을 더블클릭해도 됩니다.
   * 이미 만들어진 mp3 는 건너뜁니다(재과금 방지).
     다시 만들려면 그 파일을 지우고 실행하세요.

2) Mureka 에서 노래 만들기
      곡명 : 사랑으로 알리라
      가사 : lyrics.txt 의 [Lyrics] 부분을 복사해 붙여넣기
      스타일: lyrics.txt 의 [Style] 부분 참고
   → 내려받은 파일을 audio/03_song.mp3 로 저장

3) 이 폴더(2026-07-29-morning)를 통째로 Netlify 에 드래그 앤 드롭
   → 바로 공개 주소가 만들어집니다.


[ 주의 ]
· generate_audio_daily.py 에는 API 키가 들어 있습니다.
  Netlify 에 올릴 때는 .py 파일을 빼고 올리셔도 됩니다.
  (웹앱 재생에 필요한 것은 index.html 과 audio 폴더뿐입니다)


[ 원고를 고치고 싶을 때 ]
· content.py 를 고친 뒤
      python build_index.py
  를 실행하면 index.html 이 원고와 똑같이 다시 만들어집니다.
· 음성도 다시 만들려면 해당 mp3 를 지우고
      python generate_audio_daily.py


[ 웹앱 사용법 ]
· 화면을 한 번 누르면 시작합니다(자동재생 허용).
  시작과 동시에 '전체 무한 반복' 이 켜집니다.
· 낭독 → 강론 → 노래 → 기도 순서로 자동 연속 재생됩니다.
· ↻ 버튼 : 반복 없음 → 전체 무한 반복 → 한 메뉴 무한 반복 (3단 토글)
           '한 메뉴' 일 때는 버튼에 1 배지가 표시됩니다.
· ⏮ ⏭ : 앞뒤 건너뛰기 (3초 이후 ⏮ 은 처음으로)
· 위쪽 01~04 단추로 원하는 메뉴에 바로 이동
· 진행바를 누르면 그 위치로 이동, 🔊 로 음소거
· 키보드 : Space 재생/정지, ← → 앞뒤 이동
· audio/03_song.mp3 가 없으면 안내 후 자동으로 기도로 넘어갑니다.
