오늘의 아침 묵상 2026-07-25 · 정직한 용기 (유란시아서 143:1.7)
================================================================

폴더 구성
  index.html                  재생기 (낭독→강론→노래→기도 자동 진행)
  content.py                  본문 텍스트 (낭독·강론·노래·기도)
  generate_audio_daily.py     음성 생성 스크립트 (ElevenLabs)
  audio/                      mp3가 저장되는 폴더

배포 3단계
------------------------------------------------
1) 이 폴더에서 아래를 실행하면 음성 3개가 audio/ 에 생깁니다.
      python generate_audio_daily.py
   → audio/01_reading.mp3, 02_sermon.mp3, 04_prayer.mp3
   (이미 있는 파일은 건너뛰어 재과금이 없습니다.)

2) Mureka에서 「정직한 용기」 곡을 만들어
      audio/03_song.mp3
   로 저장하세요. (노래는 음성 스크립트로 만들지 않습니다.)

3) 이 폴더(2026-07-25-morning) 전체를 Netlify에 드래그 앤 드롭.

주의
------------------------------------------------
· generate_audio_daily.py 에는 API 키가 들어 있습니다.
  Netlify에 올릴 때 .py 파일은 빼도 됩니다(index.html + audio/ 만 있으면 재생됩니다).
· 노래 파일(03_song.mp3)이 없으면 재생기가 노래 구간을 자동으로 건너뜁니다.

재생기 기능
------------------------------------------------
· 자동 연속 재생 (낭독→강론→노래→기도)
· 전체 반복 / 한 메뉴 반복 토글 (기본: 전체 반복)
· 이전 / 다음 / 건너뛰기, 진행바 클릭 이동, 음소거
· 키보드: Space 재생·정지, ← 이전, → 다음
· 첫 화면 "탭하여 시작"은 브라우저 자동재생 정책 때문입니다.
