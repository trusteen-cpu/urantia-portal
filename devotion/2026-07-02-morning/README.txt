이 폴더에 음성 파일 4개가 들어갑니다.

1) 자동 생성 (PC에서):
     pip install requests
     python generate_audio_daily.py
   → scripture.mp3, sermon.mp3, prayer.mp3 생성

2) 노래는 수동:
     Mureka에서 만든 노래 파일을 song.mp3 라는 이름으로
     이 audio/ 폴더에 직접 넣으세요.

파일 4개(scripture / sermon / song / prayer)가 모두 있어야
index.html이 본문→강론→노래→기도 순서로 재생합니다.
