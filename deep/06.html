마키벤타 멜기세덱의 가르침과 동서양 종교에 대한 영향

6 / 39 · 2025-11-10 · 한종인

'제3 계시', 즉 마키벤타 멜기세덱의 사명과 그 가르침이 세계 종교에 미친 영향, 특히 유대교와 기독교의 성립에 이르는 과정은 유란시아(지구)의 영적 역사에서 가장 중요하고도 복잡한 흐름 중 하나입니다.

1. 마키벤타 멜기세덱의 육신화와 살렘의 복음 (제3 계시)

《유란시아서》에 따르면, 멜기세덱의 등장은 유란시아의 영적 진리가 완전히 소멸할 위기에 처했을 때 발동된 '비상 증여'였습니다.

육신화 과정 (기원전 1973년경): 아담의 사명이 실패한 이후 [ (93:1.1)], '모든 이의 아버지'라는 개념은 기원전 3000년경에 이르러 매우 희미해졌습니다 [ (93:1.1)]. 이에 유란시아를 관리하던 12명의 멜기세덱 접수자 군단은 진리의 빛을 보존하기 위해 스스로 행동하기로 결의했습니다. 그들 중 한 명인 마키벤타 멜기세덱이 이 임무에 자원했습니다 [ (93:1.2)].

그의 육신화는 예수의 탄생(여성을 통한 출생)과는 다릅니다. 그는 멜기세덱 계층의 고유한 권능을 사용하여, 특별히 준비된 인간 남성의 몸을 통해 성인(成人)의 모습으로 팔레스타인의 살렘(훗날의 예루살렘)에 나타났습니다. 그는 "아버지도 어머니도 없고, 혈통도 없으며, 날들의 시작도 끝도 없는" [ (93:9.11)] 존재, 즉 '비상시 아들'로서 활동했습니다 [ (93:0.1)].

멜기세덱의 핵심 가르침 (살렘 복음): 그의 가르침은 당시의 다신교와 주술적 신앙을 타파하는 혁명적인 내용을 담고 있었습니다.

유일신(Monotheism): 그는 '엘 엘리온(El Elyon)', 즉 "지극히 높으신 하나님"이라는 이름으로 단일하고 보편적인 우주 아버지를 선포했습니다 [ (93:4.2)].

믿음을 통한 구원 (Salvation by Faith): 이것이 멜기세덱 계시의 핵심입니다. 그는 하나님의 은총이 고통스러운 제물이나 피의 희생, 또는 복잡한 의식을 통해서가 아니라, 오직 "믿음(Faith)"이라는 단순한 조건만으로 주어진다고 가르쳤습니다 [ (93:4.3), (93:6.4)]. 이는 당시 인류에게 너무나 진보적인 개념이었습니다 [ (93:4.5)].

새로운 의식 (빵과 포도주): 그는 피를 흘리는 제사 의식을 폐지하려 노력했고, 그 대신 '빵과 포도주'를 상징적인 성례로 제시했습니다 [ (93:4.14)].

일곱 계명: 그는 "다른 신을 섬기지 말라", "믿음이 구원의 유일한 조건임을 의심하지 말라"를 포함한 단순하고 실천적인 일곱 계명을 가르쳤습니다 [ (93:4.7-93:4.13)].

미래의 증여 예고: 그는 장차 자신과 같은 하나님의 아들이, 이번에는 '여인에게서 태어날 것'이라고 예언했습니다 [ (93:3.7)].

2. 아브라함, 유대교의 성립, 그리고 멜기세덱 가르침의 변질

멜기세덱의 가르침은 그와 직접 만난 아브라함을 통해 가장 강력한 유산을 남기게 됩니다.

아브라함과의 언약: 멜기세덱은 물질적 왕국을 꿈꾸던 아브라함을 설득하여, 영적 왕국(하늘나라)의 개념을 받아들이게 했습니다 [ (93:6.1)]. 멜기세덱은 아브라함과 "네 자손이 하늘의 별과 같이 많게 될 것"이라는 언약을 맺었습니다 [ (93:6.3)].

믿음의 확증: 아브라함은 이 약속을 "믿었고, 그것이 그에게 의로 여겨졌다" [ (93:6.3)]. 이것이 바로 멜기세덱이 전하려 한 '믿음을 통한 구원'의 복음이었습니다 [ (93:6.4)].

유대교의 성립과 변질:

아브라함의 후손들(이삭, 야곱, 요셉)은 이 살렘 신앙을 이어가려 했으나 [ (93:9.5)], 시간이 지나면서 이집트의 '엘 샤다이' 개념 [ (142:3.5)], 시나이의 부족신 '야훼' [ (142:3.3)] 등 다른 신 개념들과 혼합되었습니다.

결정적 변질: 히브리 민족은 바빌론 포로기(기원전 6세기)를 거치며 극단적인 민족적 자의식에 빠졌습니다 [ (93:9.9), (97:9.27)]. 그들은 멜기세덱이 가르친 '세상을 위한 봉사' [ (97:10.1)] 대신 '선택받은 민족'이라는 특권 의식을 발전시켰습니다.

그들은 멜기세덱의 핵심인 '믿음을 통한 구원'을 거부하고, 다시 '율법, 희생제물, 의식'의 종교로 되돌아갔습니다 [ (97:10.2)]. 심지어 그들은 아브라함을 멜기세덱보다 높이기 위해, 멜기세덱에 관한 기록 대부분을 의도적으로 파괴했습니다 [ (93:9.9)].

유대교의 장점과 허점:

장점: 모든 변질에도 불구하고, 유대교는 멜기세덱이 심은 '유일신' 사상을 [ (96:1.15)] 끈질기게 보존했으며, 이는 훗날 기독교와 이슬람교가 자라날 수 있는 유일한 토양이 되었습니다 [ (97:9.29)].

허점: 멜기세덱의 영적 복음(믿음)을 민족적, 율법적 종교(행위)로 되돌려 놓았고 [ (97:10.2)], 약속된 메시야(멜기세덱이 예고한 아들)를 영적 구원자가 아닌 정치적 해방자로 오해하게 만들었습니다 [ (97:10.3)].

3. 동서양으로의 전파와 세계 종교의 형성

멜기세덱의 선교사들은 살렘에서 유라시아와 아프리카 전역으로 퍼져나가며 '한 분 하나님(유일신)'과 '믿음을 통한 구원'의 복음을 전했습니다 [ (104:1.4)]. 이 가르침이 각 지역의 기존 신앙 및 철학과 만나면서 다음과 같은 세계 종교들이 형성되었습니다.

종교 (지역)

주요 시기 (창시자)

멜기세덱 사상의 영향 (변형)

장점 (Strengths)

허점 (Flaws / Distortions)

힌두교 (인도)

기원전 1500년경~

살렘 선교사들이 '한 분 하나님'을 전파했으나 [ (94:1.5)], 베다의 '브라흐만'(절대자) 개념과 융합됨 [ (94:1.4)]. 멜기세덱의 삼위일체 개념 [ (104:1.3)]이 셋족의 영향 [ (104:1.2)]과 결합해 '브라흐마-시바-비슈누' 삼신일체로 발전 [ (104:1.5)].

심오한 철학적 깊이를 지님. 우주의 절대적 근원을 사유함.

멜기세덱의 핵심인 '믿음을 통한 구원'을 거부함 [ (94:1.5)]. 복잡한 의식, 사제 계급, 형이상학에 치중하여 '개인적 하나님'을 잃어버리고 비인격적인 '절대자' 개념으로 빠짐 [ (94:11.12)].

불교 (인도/아시아)

기원전 6세기 (고타마 싯다르타) [ (92:5.9)]

힌두교의 철학적 배경(멜기세덱 사상의 변형)에서 발생함.

높은 윤리적, 도덕적 가르침. 미신 타파 시도. 후기 대승불교(아미타 신앙)는 '믿음을 통한 구원' 개념을 재발견함 [ (94:12.2), (94:12.3)]. 모든 종교에서 진리를 수용하는 개방성 [ (94:12.4)].

창시자 고타마를 신격화함 [ (94:12.1)]. 신(神) 개념이 '절대자'로 남아 비인격적이고 모호해짐 [ (94:11.12)]. 구원이 '믿음'이 아닌 '스스로의 깨달음'에 의존함.

도교 (중국)

기원전 6세기 (노자) [ (92:5.9)]

살렘 선교사들의 영향을 받아 '도(Tao)'를 만물의 첫째 원인이자 유일신 개념으로 발전시킴 [ (131:8.1)].

멜기세덱의 유일신 진리를 가장 잘 보존한 종교 중 하나 [ (131:8.1)]. 우주적 조화와 자연스러운 믿음을 강조함.

노자는 하나님을 '도'로 보았으나 [ (92:5.9)], 후대에 마법, 주술, 다신교와 섞이며 본래의 높은 영적 수준을 상실함.

조로아스터교 (페르시아)

기원전 6세기 (조로아스터) [ (92:5.9)]

멜기세덱의 유산을 이어받아 유일신 '아후라 마즈다'를 선포함 [ (95:6.9)].

높은 수준의 유일신 사상과 강력한 윤리적 메시지(빛과 어둠의 투쟁) [ (92:5.9)].

선과 악의 이원론적 개념에 영향을 받음 [ (92:5.9)]. 사후에 부활한 고대 '미트라' 신앙(희생 제의)과 혼합됨 [ (95:6.7)].

그리스 철학 (유럽)

기원전 6-4세기 (플라톤 등) [ (92:5.9)]

살렘의 가르침(특히 반(反)사제주의)이 영향을 미쳤으나 [ (98:1.5)], 기존의 올림푸스 신화(미학적 종교)가 너무 약했음 [ (98:1.6)].

높은 수준의 지적 발전과 이성적 사고를 이룸 [ (98:2.7)].

'믿음'을 잃고 '이성'과 '철학'으로 종교를 대체하려 했으나 [ (98:2.2)], 대중의 영적 갈증을 채우지 못함 [ (98:2.3)].

미트라교 (로마/페르시아)

기원전 1세기~

변질된 조로아스터교에서 부활하여 [ (95:6.7)] 로마 제국 전역에 퍼짐 [ (98:5.1)].

구원자, 구속자, 희생의 개념을 통해 대중에게 강력히 호소함 [ (98:4.2)].

멜기세덱이 거부했던 '피의 희생을 통한 구원'이라는 원시적 개념으로 완전히 되돌아감 [ (121:7.8), S_R38].

4. 기독교의 발생: 멜기세덱 복음의 재현과 타협

이러한 배경 속에서 '제4 계시'인 나사렛 예수(네바돈의 미가엘)가 유란시아에 오셨습니다.

예수의 사명 (제4 계시): 예수는 멜기세덱이 예고한 [ (93:3.7)] 바로 그 아들이었습니다. 그의 사명은 멜기세덱이 가르쳤으나 유대교가 잃어버린 '믿음을 통한 구원'과 '하나님의 아버지 되심'이라는 복음을 [ (93:3.8)] 자신의 '삶'으로 다시 계시하는 것이었습니다.

초기 기독교의 성립: 예수 승천 이후, 사도 바울은 로마 시민이자 헬레니즘화된 유대인으로서 [ (121:1.2)], 이 새로운 복음을 로마 제국에 전파하는 데 결정적인 역할을 했습니다.

위대한 타협 (The Great Compromise): 그러나 바울이 세운 '기독교'는 예수(와 멜기세덱)의 순수한 복음 그 자체가 아니라, 당시 지중해 세계의 다양한 사상들이 혼합된 '타협'의 산물이었습니다 [ (195:1.4)].

예수의 가르침 (핵심): '하나님의 아버지 되심'과 '인류의 형제애'라는 복음.

유대 신학 (토대): 유일신 사상. 그러나 멜기세덱이 거부한 '대속 교리(Atonement Doctrine)' [ (149:2.3), S_R39]—즉, 예수가 진노한 하나님을 달래기 위한 '희생 제물'이 되었다는 유대적 개념—를 치명적으로 받아들였습니다 [ (149:2.3), S_R39].

그리스 철학 (논리): 알렉산드리아의 필로(Philo)와 같은 철학자들의 사상(플라톤 철학)을 받아들여 신학적 체계를 세웠습니다 [ (121:6.3), (121:6.5)].

미트라교/신비 종교 (의식): 기독교의 최대 경쟁자였던 미트라교의 '구속', '희생을 통한 구원' 개념 [ (121:7.8), S_R38] 및 프리지아 신비 종교의 '검은 금요일'(신(神)의 죽음)과 '사흘 만의 부활' 축제 [ (98:4.4)] 같은 요소들이 기독교 교리에 흡수되었습니다.

결론: 기독교의 장점과 허점

장점: 기독교는 유대교의 높은 도덕성, 그리스의 철학, 로마의 조직력, 그리고 신비 종교의 감동적인 구원 메시지를 영리하게 결합(타협)함으로써 [ (195:1.4)] 서구 문명을 지배하는 종교가 되었습니다.

허점: 이 과정에서 멜기세덱과 예수가 전한 "믿음으로 거저 얻는 구원"이라는 핵심 진리가 다시 가려졌습니다. 기독교는 '진노한 신을 달래기 위한 피의 희생'이라는, 멜기세덱이 그토록 없애려 했던 원시 종교의 개념 [ (93:6.4)]을 그 교리의 중심(대속 교리)에 두는 [ (149:2.3), S_R39] 역사적 아이러니를 갖게 되었습니다.
