깃허브 + 넷리파이 + 관리자 화면 설치 안내
════════════════════════════════════════════════════════════

이 순서대로 하시면, 앞으로는 홈페이지 주소 뒤에 /admin 을 붙여 들어가
고치고 [Publish] 만 누르면 끝납니다. 파일을 내려받고 덮어쓰고 올리는
일이 없어집니다. 휴대폰에서도 됩니다.

한 번만 하는 설정이고, 대략 20~30분 걸립니다.
중간에 막히면 어느 단계에서 무엇이 보이는지 알려 주세요.


───────────────────────────────────────────────
1단계.  깃허브에 저장소 만들고 파일 올리기
───────────────────────────────────────────────

 1) github.com 에 로그인
 2) 오른쪽 위 [+] → New repository
 3) Repository name 에  urantia-portal  (다른 이름도 됩니다)
    · Public / Private 아무거나 괜찮습니다
    · Add a README 는 체크하지 마세요
 4) [Create repository]
 5) 다음 화면에서  uploading an existing file  글씨를 누릅니다
 6) 이 폴더 안의 것을 전부 끌어다 놓습니다

    ★ 중요 ★  폴더째 말고, 폴더를 열어서 안의 것 전부를 끌어다 놓으세요.
      index.html / list.html / app.js / links.json / style.css /
      netlify.toml / admin 폴더 / images 폴더

 7) 아래 [Commit changes] 누르기


───────────────────────────────────────────────
2단계.  config.yml 한 줄 고치기
───────────────────────────────────────────────

 1) 깃허브에서 admin 폴더 → config.yml 클릭
 2) 연필 아이콘(Edit) 클릭
 3) 위에서 세 번째 줄

        repo: 깃허브아이디/저장소이름

    을 본인 것으로 바꿉니다. 예)

        repo: trusteen/urantia-portal

    ※ 주소창을 보시면 github.com/뒤에 그대로 적혀 있습니다.
 4) [Commit changes]


───────────────────────────────────────────────
3단계.  넷리파이에 깃허브 연결하기
───────────────────────────────────────────────

 ※ 지금까지 쓰시던 드래그 앤 드롭 사이트와는 따로 새로 만듭니다.
   잘 되는 것을 확인한 뒤에 옛 사이트를 지우시면 됩니다.

 1) app.netlify.com 로그인
 2) [Add new site] → [Import an existing project]
 3) [Deploy with GitHub] → 권한 허용
 4) 방금 만든 저장소(urantia-portal) 선택
 5) 설정 화면이 나오면 그대로 두고 [Deploy]
    (Build command 는 비워 둠, Publish directory 는 . 또는 비움)
 6) 1분쯤 뒤 주소가 나옵니다 → 눌러서 홈페이지가 보이는지 확인
 7) Site configuration → Change site name 에서 주소를 예쁘게 바꾸세요
    예)  urantia-korea.netlify.app


───────────────────────────────────────────────
4단계.  깃허브 로그인 열쇠 만들기 (OAuth)
───────────────────────────────────────────────

 관리자 화면에 로그인하려면 깃허브와 넷리파이를 이어 주는 열쇠가
 하나 필요합니다. 한 번만 만들면 됩니다.

 [4-1] 깃허브에서 열쇠 만들기

  1) github.com → 오른쪽 위 프로필 → Settings
  2) 맨 아래 왼쪽 Developer settings
  3) OAuth Apps → [New OAuth App]
  4) 이렇게 채웁니다

       Application name          : Urantia Portal CMS
       Homepage URL              : https://내사이트주소.netlify.app
       Authorization callback URL: https://api.netlify.com/auth/done

     ★ 세 번째 칸은 반드시 위 주소 그대로 넣으세요. 내 사이트 주소가
       아닙니다. 여기가 가장 많이 틀리는 곳입니다.

  5) [Register application]
  6) Client ID 가 보입니다 → 복사해 둡니다
  7) [Generate a new client secret] → 나오는 긴 글자도 복사해 둡니다
     ★ 이 글자는 창을 닫으면 다시 못 봅니다. 메모장에 붙여 두세요.

 [4-2] 넷리파이에 열쇠 넣기

  1) 넷리파이에서 내 사이트 → Site configuration
  2) 왼쪽 Access & security → OAuth (또는 Authentication providers)
  3) Authentication providers 의 [Install provider]
  4) GitHub 선택
  5) 방금 복사한 Client ID 와 Client Secret 붙여넣기 → [Install]


───────────────────────────────────────────────
5단계.  관리자 화면 들어가기
───────────────────────────────────────────────

 1) 브라우저에서

        https://내사이트주소.netlify.app/admin/

    ★ 맨 뒤 빗금(/) 까지 붙여 주세요.

 2) [Login with GitHub] 누르기 → 깃허브 로그인 → 권한 허용
 3) 왼쪽 "홈페이지 → 링크 목록" 클릭
 4) 그룹을 펼쳐 이름과 주소를 고칩니다
 5) 오른쪽 위 [Publish] 클릭

 → 깃허브에 저장되고, 넷리파이가 알아서 홈페이지를 새로 만듭니다.
   30초에서 1분쯤 뒤 홈페이지에 반영됩니다.

 이제 끝입니다. 앞으로는 5단계만 반복하시면 됩니다.


───────────────────────────────────────────────
관리자 화면 쓰는 법
───────────────────────────────────────────────

 · ③ 그룹 을 펼치면 그룹들이 나옵니다. 그룹을 누르면 게시판 목록.
 · 게시판을 누르면 이름 / 주소 / 회원 전용 / 하위 가 나옵니다.
 · 하위 안에 또 "하위의 하위" 가 있습니다. 세 층까지 됩니다.
 · 왼쪽의 점 여섯 개(⠿)를 끌면 순서가 바뀝니다.
 · 오른쪽 [x] 로 지웁니다.
 · 새로 넣을 때는 목록 맨 아래 [Add ...] 단추.
 · 다 고쳤으면 반드시 오른쪽 위 [Publish] → Publish now.

 ★ [Publish] 를 안 누르면 저장되지 않습니다. 초안으로만 남습니다.


───────────────────────────────────────────────
자주 막히는 곳
───────────────────────────────────────────────

 · 로그인 창이 떴다가 그냥 닫힌다
     → 4-1 의 callback URL 을 다시 보세요.
       반드시  https://api.netlify.com/auth/done

 · "Error loading the CMS configuration"
     → 2단계의 repo: 줄이 잘못됐습니다. 띄어쓰기·대소문자 확인.

 · 로그인은 되는데 "Failed to load entry"
     → links.json 이 저장소 맨 위(루트)에 있는지 확인.
       admin 폴더 안이 아니라 index.html 과 같은 자리여야 합니다.

 · 고쳤는데 홈페이지가 그대로다
     → 1분 기다린 뒤 Ctrl + F5 (강력 새로고침).
       넷리파이 Deploys 탭에서 "Published" 인지도 확인해 보세요.


───────────────────────────────────────────────
알아 두실 점
───────────────────────────────────────────────

 · 이 방식은 깃허브 계정으로 로그인합니다. 다른 분에게 편집을 맡기려면
   그분도 깃허브 계정이 있어야 하고, 저장소에 초대(Settings →
   Collaborators)해 주셔야 합니다.

 · 예전에 쓰던 admin.html 도 폴더에 그대로 두었습니다. 인터넷이 없거나
   급할 때 쓰는 예비 편집기입니다. 다만 그것으로 고치면 예전처럼
   파일을 덮어쓰고 올려야 하니, 평소에는 /admin 만 쓰시는 편이 낫습니다.

 · 넷리파이의 옛 로그인 기능(Identity)과 Git Gateway 는 지원이 끊겼습니다.
   그래서 깃허브 로그인 방식으로 만들었습니다. 앞으로도 계속 쓸 수 있는
   방식입니다.
