한국 유란시아서 독자 모임 · 링크 포털
────────────────────────────────────────────

★ 관리자 화면을 /admin 으로 옮기시려면
   같은 폴더의 「설치안내-깃허브관리자.txt」 를 보세요.
   깃허브 + 넷리파이를 이어 두면 파일을 내려받고 올리는 일이 없어집니다.

■ 들어 있는 파일
   index.html    첫 화면 (게시판 이름만 빼곡히)
   list.html     하위 페이지 (2단·3단을 모두 이 파일 하나가 그립니다)
   page.html     글 페이지 (주소 대신 글을 넣었을 때 열립니다)
   app.js        두 페이지가 함께 쓰는 도우미 (장식 그림도 여기서 그립니다)
   links.json    ★ 모든 링크가 들어 있는 데이터 파일 ★
   style.css     디자인
   admin/        관리자 화면 (홈페이지주소/admin 으로 들어갑니다)
   admin.html    예비 편집기 (인터넷 설정 전이나 급할 때만)
   netlify.toml  넷리파이 설정
   images/       사진이 쌓이는 폴더
   files/        첨부 파일이 쌓이는 폴더

■ 넷리파이에 올리는 법
   1) 이 폴더에서 admin.html 을 뺍니다.  (올려도 위험하진 않지만 헷갈립니다)
   2) 남은 폴더를 통째로 넷리파이에 드래그 앤 드롭.
   끝입니다.

■ 링크를 고치거나 추가할 때
   1) admin.html 을 더블클릭해서 엽니다.
      → "links.json 을 자동으로 읽지 못했습니다" 가 뜨면
        [📂 파일 불러오기] 로 links.json 을 골라 주세요.
   2) 이름과 주소를 고칩니다.
      · 주소 = 카페에서 그 게시판을 열었을 때 주소창에 뜨는 것을 복사해 붙여넣기
      · [+하위] 를 누르면 하위가 생깁니다. 하위 줄에도 [+하위] 가 있어
        "게시판 → 하위 → 하위의 하위" 세 층까지 됩니다
      · [회원] 을 켜면 "회원 전용" 표시가 붙습니다
      · ▲▼ 로 순서 변경, ✕ 로 삭제
   3) 맨 위 [💾 links.json 저장] 을 누르면 파일이 내려받아집니다.
   4) 그 파일을 이 폴더의 links.json 자리에 덮어쓰고,
      폴더를 다시 넷리파이에 드래그 앤 드롭.

   ※ 주소를 안 넣은 항목은 회색 "주소" 표시가 붙고,
     눌렀을 때 카페 대문으로 갑니다. 주소를 넣으면 표시가 사라집니다.
     관리자 화면 위쪽에 "주소 비어 있음 N개" 가 늘 보입니다.

■ 일요 스터디 일정을 구글 시트로 관리하려면
   1) 구글 시트에 표를 만듭니다.  예)  날짜 | 제목 | 링크
   2) 파일 → 공유 → 웹에 게시 → 형식을 "쉼표로 구분된 값(.csv)" 로 → 게시
   3) 나온 주소를 복사
   4) admin.html 에서 [📅 구글시트 일정] 을 누르고 붙여넣기 → 저장 → 업로드
   이후로는 시트에 한 줄만 적으면 홈페이지에 바로 뜹니다. 업로드 필요 없습니다.

■ 첫 화면 문구 바꾸기
   admin.html 의 [⚙ 제목·인용구] 에서 제목·부제·인용구·한 문장 요약을 고칩니다.

■ 항목이 아주 많을 때 (196편 같은 목록)
   1) 그룹 제목줄의 [📝 목록 한꺼번에 편집] 을 누릅니다.
   2) 큰 칸이 열립니다. 한 줄에 하나씩 이렇게 적습니다.

        제1편 우주 아버지 | https://cafe.naver.com/…/1
        제2편 하나님의 본성 | https://cafe.naver.com/…/2
           오디오북 | https://youtu.be/…          ← 공백 3칸(탭 1번) = 하위
              1부 낭독 | https://youtu.be/…       ← 공백 6칸(탭 2번) = 하위의 하위
        공지 게시판 | | 회원                       ← 맨 뒤 "| 회원" = 회원 전용 표시

      주소가 아직 없으면 이름만 적고 넘어가도 됩니다.
   3) [이 내용으로 바꾸기] 를 누르면 그 그룹의 목록이 통째로 바뀝니다.

   ※ 엑셀에서 만들어 붙여넣어도 됩니다.
     엑셀 두 칸(이름/주소)을 복사하면 사이가 탭으로 붙는데,
     그대로 붙여넣지 말고 가운데를 | 로 바꿔 주세요.
     (엑셀 C열에  =A1&" | "&B1  을 넣고 그 열을 복사하면 가장 편합니다)

■ 화면이 길어지지 않게
   · 항목이 12개가 넘는 그룹은 처음에 접혀 있습니다. 제목 왼쪽의 ▶ 로 펼칩니다.
   · 펼쳐도 한 번에 30줄만 보이고, 아래에 [30개 더 보기] / [전부 펼치기] 가 나옵니다.
   · 위쪽 [모두 접기] / [모두 펼치기] 로 한꺼번에 조절합니다.
   · 찾기 칸에 이름을 치면 모든 그룹에서 그 줄만 걸러 보여 줍니다.

■ 그룹 사이로 항목 옮기기
   [옮기기] 를 누르고 옮길 그룹을 고르면 됩니다. 하위 항목이 있으면 함께 따라갑니다.

■ 참고
   · 첫 화면에는 게시판 이름만 깔립니다. 하위는 보이지 않습니다.
   · 게시판을 누르면
        하위가 없으면  → 그 주소로 바로 이동
        하위가 있으면  → 하위 페이지가 열립니다 (이름 앞에 ▸ 표시)
   · 하위 페이지에서 또 누르면
        하위의 하위가 없으면 → 그 주소로 이동
        있으면              → 하위의 하위 페이지가 열립니다
   · 그룹 이름(참여 게시판, 유란시아서 연구 …)은 링크가 아니라 묶음 머리글입니다.
   · 검색창은 세 층 전부를 한 번에 찾습니다.
   · 검색창 아래 그룹 칩을 누르면 그 카드로 바로 뜁니다. 게시판이 몇백 개로 늘어도
     첫 화면에서 길을 잃지 않습니다.
   · 한 그룹이 아주 커질 때만(기본 40개 초과) 카드에 [전체 N개 보기 →] 가 생깁니다.
     이 기준은 관리자의 "최대표시" 숫자로 바꿉니다.

■ 주소 대신 "글"을 넣고 싶을 때  (인사말·소개·공지 등)
   관리자에서 그 항목의 [글] 칸에 내용을 쓰면 됩니다.
   글이 있으면 눌렀을 때 카페가 아니라 그 글이 열립니다.

   우선순위:  하위가 있으면 → 하위 목록
              글이 있으면   → 글 페이지
              둘 다 없으면  → 주소 (주소도 없을 때만 카페 대문)

   글을 지우면 다시 주소로 돌아갑니다. 글과 주소를 함께 넣어 두면
   글이 열리고, 글 아래에 [원문 보러 가기 ↗] 단추가 생깁니다.

   글 쓰는 법 (몰라도 그냥 줄글로 쓰시면 됩니다)
        # 큰 제목          ## 작은 제목
        - 목록             > 인용구
        **굵게**           [글자](https://주소)
        ---  가로줄        빈 줄로 문단을 나눕니다

■ 사진과 첨부 파일  (관리자 화면에서만 올립니다)
   그 항목의 칸에 넣으면 글 페이지에 함께 나옵니다.

     대표 사진   글 맨 위에 큰 사진 한 장
     사진첩      여러 장을 격자로. 누르면 원본 크기로 열립니다
     첨부 파일   pdf·한글·엑셀·mp3 등. [내려받기] 단추로 나옵니다

   · 사진은 images 폴더, 첨부는 files 폴더에 자동으로 들어갑니다.
   · 사진은 올리기 전에 가로 1200픽셀쯤으로 줄이시면 화면이 빨라집니다.
   · 큰 파일(50MB 넘는 영상·오디오)은 올리지 마시고
     유튜브나 구글 드라이브에 두고 주소만 거세요. 저장소가 무거워집니다.
   · 글 없이 사진이나 첨부만 넣어도 글 페이지가 열립니다.

■ 방문자가 글을 쓰거나 파일을 올리는 기능은 없습니다
   이 홈페이지는 서버가 없는 방식이라 방문자 쓰기는 되지 않습니다.
   그 몫은 네이버 카페가 맡고, 홈페이지는 보여 주는 일을 맡는 구조입니다.
   꼭 필요하시면 구글 폼을 만들어 링크로 걸어 두는 방법이 가장 간단합니다.

■ 하위 페이지 꾸미기
   · 하위 페이지는 그룹 색을 띠는 머리 띠 + 빵부스러기(홈 › 그룹 › 항목)로 시작합니다.
   · 목록은 2~4단으로 흐르고, 여섯 칸마다 유란시아서 인용구가 담긴 그림 판이 끼어듭니다.
   · 그림은 이미지 파일이 아니라 코드로 그리므로 늦게 뜨거나 깨지지 않습니다.
   · 인용구를 바꾸시려면 links.json 의 site.quotes 에서 t(문장)와 r(출처)를 고치세요.
   · 검색창은 첫 화면·목록 페이지 모두에서 하위 3단 항목까지 찾습니다.
