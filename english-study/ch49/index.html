카카오톡 안에서 열렸습니다. 소리가 나지 않으면 오른쪽 아래(기기에 따라 오른쪽 위) 점 세 개를 누르고 다른 브라우저로 열기를 고르십시오. 크롬이나 사파리로 열면 정상으로 작동합니다.

처음 오셨나요?

휴대폰에서 카톡 링크로 여셨다면 오른쪽 아래 점 세 개 → 다른 브라우저로 열기를 먼저 눌러 주십시오. 카톡 안의 간이 브라우저에서는 소리와 마이크가 막힐 수 있습니다. 자주 쓰실 분은 즐겨찾기에 넣어 두십시오.

공부 순서는 이렇습니다. 절을 누른다 → 나팔로 원문을 듣는다 → 점선 친 단어와 Words로 뜻을 익힌다 → In plain English로 뜻을 잡는다 → KOR로 한글 번역을 확인한다 → 질문 세 개에 영어로 답해 본다 → Reflection(영어 강론)으로 마무리한다. 한 절에 10분, 하루 두세 절이 알맞습니다.

Fix my English(말한 영어를 고쳐 주는 기능)만 각자 앤트로픽 Claude API 키가 필요합니다. console.anthropic.com에서 키를 만들어 오른쪽 위 설정에 넣으시면 됩니다. 키가 없어도 듣기·단어·해설·질문·강론은 모두 됩니다. 챗지피티나 제미나이 키는 쓸 수 없습니다.

크롬에서 가장 잘 됩니다. 설정에서 읽는 속도를 고를 수 있습니다.
